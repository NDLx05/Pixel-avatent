# Asset provenance

## Supplied assets

All files in `assets/characters/` were copied from the user's `PixelWorld_Character_Art_Pack.rar`. Original atlas image bytes are preserved. The source pack contains 3 heroes and 8 monsters, plus their animation manifest.

The supplied README states that its upstream ZIPs do not contain a clear LICENSE/NOTICE and that permission should be verified before public/commercial distribution. No broad license is granted for those third-party images by this project. This is an actual unresolved provenance limitation of the provided pack, not a finding that the user lacks permission.

The reference image uploaded as `tải xuống` was consulted for visual direction only. It is not shipped as a game background and is not decomposed into new assets.

## Newly authored work

Game source, Canvas environment drawings, fox/chicken procedural animation, UI, icon SVG and synthesized audio were created for this project. No additional external image/font/music downloads are required by the runtime. The PNG app icons are rasterizations of the authored SVG.
